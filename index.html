步骤 1 / 5 · 固定数据

01 / 固定输入

先明确“依据是什么”

读取同一业务范围内的合成快照，关联来源、观察时间和适用规则。必填数据缺失或过期时，停止生成候选。

本步骤留下的关联证据 · 教学示意
数据来源示例售电业务 · 合成数据
数据快照固定输入与观察时间
规则依据关联适用规则及版本

算法启用与交易授权分别管理。每一步保留关联证据。

固定数据 → 调用获准算法 → 结构化候选 → 交易授权与后端校验 → 模拟执行与回执。
额度示例（已核销／仍占用）：提交 0／4,000 → 部分成交 1,600／2,400 → 核对超时 1,600／2,400 → 确认全成 4,000／0 元。
算法启用位于版本发布环节；具体交易逐次核验授权条件。教学数值不代表真实报价或收益。05 / 07

05 / 两种学习路径

Learn the business · Validate the algorithm

经验持续积累，算法经过验证再启用

交易员的带教与纠偏、授权资料和执行复盘，共同为两条学习路径提供依据。

01 / 业务经验学习

让 Bot 更懂业务

保留来源、适用条件与局限

  1. 经验提炼

    整理判断理由
    复盘场景与停止条件

  2. 记忆与 Skill

    沉淀业务知识
    形成可复用工作方法

  3. 使用与纠错

    在授权业务中应用
    持续核查和修正

02 / 独立算法改进

让计算有验证依据

当前以固定算法参数候选为主

  1. 改进候选

    固定假设
    记录变化与来源

  2. 训练与验证

    留出检验、约束检查
    目标包含影子运行

  3. 人工启用

    审核证据
    发布固定版本

  4. 授权后使用

    按新版本
    重新取得交易授权

影响交易量价、约束或风险预算的 Skill 改动，也进入受控版本流程。

业务经验积累不等于模型权重自动更新；新算法版本不继承旧交易授权。

已有记忆／Skill 基础及参数候选流程；独立强化学习与完整算法插件发布仍待实施。06 / 07

06 / 经验交接 · 已确认待实施

Versioned experience · Independent growth

让经验在新业务中继续积累

旧业务积累的经验，经明确授权与固定版本交接，成为新 Bot 的起点。

  1. 01 / 选择与授权

    选定可交接经验

    从记忆、经验与 Skill 中
    选取获准导出和使用的内容

  2. 02 / 固定版本

    形成经验交接包

    保留来源、版本、适用条件
    以及已知局限

  3. 03 / 独立导入

    新 Bot 接纳副本

    按目标业务重新配置权限
    保留导入记录与原包

  4. 04 / 验证与积累

    在新业务中成长

    核查适用性、纠错与复盘
    继续积累自己的经验

后续更新，由目标明确接纳

源 Bot 或 Skill 更新形成新包；目标独立积累，源修改不自动覆盖目标内容。

经验可交接，权限分别管理

凭据、角色权限、算法启用批准、交易授权与额度，都不随经验导入继承。

业务可以结束，获授权的经验可以继续使用。原始交易证据仍归属原业务。

固定版本交接已确认，完整交接包、独立导入与追溯闭环待实施；现有记忆、Skill 和 Agent 导入作为基础。07 / 07
